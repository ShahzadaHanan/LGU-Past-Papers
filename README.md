# LGU Past Papers & Online Lectures Platform

## Project Overview

The LGU Past Papers & Online Lectures Platform is a custom-built academic resource portal for Lahore Garrison University.

The system allows students to:

* Browse past papers by Department → Degree → Exam Type
* View and download papers
* Access online lectures
* Book paid online classes
* Subscribe for new paper notifications
* Submit papers for review

The entire platform is built with a custom MVC architecture without using Laravel or any PHP framework.

# Current Progress Summary

Completed:

* **Dockerized Development Environment** (PHP 8.3+, Apache, MySQL 8.x, phpMyAdmin).
* **Base MVC Core framework** (Custom Dependency Injection container, Reflection class resolver, Router, HTTP Request/Response helpers, Custom views compiler with base layouts, Session support, CSRF verification, and Form data validation).
* **Database Setup & Migrations**: Sequence-based database migrations runner (`database/migrate.php`) successfully executing structure queries and seeding the default super-admin.
* **Backend Admin CRUD Modules**: Full Model-Repository-Service stack implemented for:
  * Departments & Sub-Departments (Degrees)
  * Hero Slides (home banner)
  * Repeatable Content Blocks (flexible layout builder)
  * Video Categories & Video Lectures (with YouTube URL regex extraction and HQ thumbnail rendering)
  * Past Papers (assigning Mid/Final/Summer exam types, uploading snapshots/solutions, and converting uploads to WebP formats)
  * Class Bookings (featuring status selectors and CSV exports)
  * Paper Submissions (moderation workflow: review submissions and promote approved assets into database)
  * Newsletter Subscribers (list views, opt-in flags, and CSV exports)
  * Alumni Testimonials & Testimonial cards
  * Site Settings (dynamic footer values, helpline WhatsApp numbers, Google Analytics tracking IDs, and canonical parameters)
  * User Accounts Administration (allowing Super Admins to manage edit permissions and hash passwords secure-Bcrypt)
* **Frontend Public Templates**: Complete set of responsive pages integrated with local-storage Dark/Light themes, styling layouts, and floating WhatsApp click-to-chat links:
  * Home (hero carousels, dynamic content loops, grid departments, newsletter subscription inputs, and first-visit announcements)
  * All Departments list and specific Department detail view (listing degrees and department career guides)
  * Degree view (accordion toggle filters displaying mid-term and final-term exams)
  * Paper view (image preview lightbox zooms, download handlers, related items, and Breadcrumbs structured schema)
  * Lectures (category tag menus, video iframe links, see-more paginated loading, and Book Class form submissions)
  * About LGU, About Us, Alumni, and Contact Us (with past paper contribution forms)
* **SEO PASS**: Clean SEO dynamic URLs, on-the-fly Breadcrumb JSON-LD schemas, automated sitemap.xml generator (`cron/generate_sitemap.php`), and custom robots.txt setup.
